What I plan to do:
- YOLO26 model pretrained from COCO on ~8,000 subset
  - YOLOv8, YOLO11 use Distribution Focal Loss (DFL) for box-regression which instead of predicting each box edge as a single number 
    (as seen in lecture with (x, y, h, w)), it instead predicts a probability distribution over a set of bins, then final edge = expectation 
    over the distribution. 
  - DFL based approaches cost extra output channels, which is why YOLO26 drops it. 
  - YOLO comes in nano (n, ~2.6M params), s (small, ~9.4M params), m (medium, ~20M params), l (large), and x (extra-large). 
    - s fits T4 GPU comfortably. 

- Can also try frozen backbone (just need the freeze=x arg)
- My YOLO26s was tested on 508 images
- bird has bad recall -> A lot of FN
- decimal next to predicted box symbolizes detection confidence (class X, box overlap)
- F1 = 2*(precision*recall) / (precision + recall)
- precision = TP/TP+FP
- recall = TP/TP+FN
